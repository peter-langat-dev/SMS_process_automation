# Automating SMS Data Entry, Cleaning, and Financial Reporting

## Project Overview

This project demonstrates how repetitive financial data-processing tasks can be automated, from entering SMS transaction data to cleaning, sorting, filtering, and generating a financial report.

The goal is to transform raw SMS transaction messages into structured, organised, and usable financial data, reducing manual work and improving the efficiency of financial record-keeping.

## The Problem

Financial information received through SMS messages may require repeated manual entry into spreadsheets before it can be analysed. This process can be time-consuming and may introduce errors, inconsistencies, duplicate records, or missing information.

When transaction data is not properly organised, preparing accurate financial summaries and reports becomes more difficult.

## Project Objectives

- **Automate data entry:** Reduce repetitive manual entry of SMS transaction information.
- **Clean the data:** Standardise transaction details, identify missing values, and check for inconsistencies and duplicates.
- **Sort and filter records:** Organise transactions by relevant fields, such as date, transaction type, or amount.
- **Generate financial reports:** Convert processed transaction data into meaningful summaries that support financial monitoring and decision-making.
- **Improve data quality:** Make financial records more consistent, traceable, and easier to review.

## Workflow

1. **Data collection:** Obtain SMS transaction data for processing.
2. **Data extraction:** Identify relevant transaction details, such as dates, references, descriptions, and amounts.
3. **Data cleaning:** Standardise formats and check for errors, duplicates, and incomplete records.
4. **Data organisation:** Sort and filter transactions to support analysis.
5. **Financial reporting:** Summarise the processed data into a structured financial report.
6. **Verification:** Compare the processed records and report totals against the original transaction data.

## Expected Benefits

- Less time spent on repetitive data entry.
- Fewer manual processing errors.
- More organised and searchable transaction records.
- Faster preparation of financial reports.
- Improved visibility into financial transactions.
- A repeatable workflow that can be adapted to similar data-processing tasks.

## Tools and Technologies

The tools used depend on the implementation of the project. They may include:

- Microsoft Excel for data organisation and reporting.
- Python and pandas for data cleaning and processing, if implemented.
- Automation scripts or other tools for extracting transaction details from SMS messages.
- In this particular project I have used Excell's Power Query

## Project Scope

This project focuses on automating the processing of SMS transaction data and converting it into a structured financial report. The workflow can be adapted to different transaction formats and reporting requirements.

The quality of the output depends on the accuracy of the source messages, the extraction rules, and the validation procedures.

## Conclusion

Automating SMS data processing demonstrates how routine administrative and financial tasks can be transformed into a more efficient, consistent, and repeatable workflow. By reducing manual handling and organising transaction information, the process supports faster reporting and better-informed financial decisions.
